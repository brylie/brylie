## 💼 Featured Technical Projects

### [Tapio](https://github.com/brylie/tapio)
**Production RAG System for Finnish Immigration Information**

A complete RAG pipeline built with LangChain for extracting, processing, and querying information from Finnish government websites. The system handles web crawling, content parsing, vectorization with HuggingFace embeddings, and semantic search across multiple vector databases (ChromaDB, Pinecone, pgvector, Astra DB).

**Key Features:**
- Modular architecture separating crawling, parsing, vectorization, and retrieval
- Multi-database support with abstraction layer for flexible deployment
- Local LLM integration with Ollama for privacy-focused inference
- Production engineering practices: comprehensive tests, type checking (mypy), automated quality gates
- Interactive chatbot interface with Gradio

*Technologies: Python, LangChain, ChromaDB, Pinecone, pgvector, Astra DB, Ollama, HuggingFace, Gradio*

### [Agent Skills](https://github.com/brylie/agent-skills)
**Lightweight Format for Extending AI Agent Capabilities**

A collection of skills in the Agent Skills format, an open format for extending AI agent capabilities with specialized knowledge and workflows. This project demonstrates practical approaches to making AI agents more capable and context-aware.

*Technologies: Markdown, YAML, AI agent frameworks*

### [Language Lesson Chat](https://github.com/brylie/language-lesson-chat)
**AI-Powered Language Learning Companion**

An interactive web application that helps language learners practice realistic, context-specific scenarios. The app combines AI with structured lessons to create immersive learning experiences.

*Technologies: Python, AI/ML frameworks, Web technologies*

### [Piano Fitness](https://github.com/PianoFitness/app)
**Technical Development Tool for Piano Students**

A specialized mobile application designed to help piano students and teachers focus on technical development through interactive exercises, real-time feedback, and progress tracking. Built with precise MIDI integration to complement repertoire practice with targeted exercises for building coordination and muscle memory.

*Technologies: Flutter, Dart, MIDI integration*
